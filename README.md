# Fallow Ground

Next.js site for Fallow Ground Ministries.

## Local development

Use `pnpm` for all package management commands:

- Node: `22.x`

```bash
pnpm install
pnpm dev
pnpm build
pnpm start
```

## Vercel

This repository is set up for Vercel's standard Next.js deployment flow.

- Framework preset: auto-detected as `Next.js`
- Install command: `pnpm install`
- Build command: `pnpm build`
- Output: standard Next.js output

No `vercel.json` is required for the current app.
